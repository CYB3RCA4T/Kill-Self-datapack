# Kill Self Datapack

The **Kill Self** datapack adds a simple utility command that lets players kill themselves in game  
Perfect for testing maps, servers, or just a quick reset when things go wrong.

## 📌 Features
- Adds the `/trigger kill_self` command automatically.  
- Works in survival, adventure, and creative mode.  
- Multiplayer friendly – each player can use it independently.  
- Lightweight and vanilla-friendly: no mods required.  

## 🚀 Installation

If you don't have a world:

1. Download the release matching your version  
2. Open your downloads folder
3. Copy/Cut the `.zip` file downloaded previously
4. Start your game instance
5. Create a world
6. Go to more then select datapacks
7. Select open datapacks folder
8. Paste in the `.zip` file
9. Close the file explorer window
10. Move from 'Available' to 'Selected' then click 'Done'.
11. Done!

If you already have a world:  
1. Download the release matching your version
2. Open your downloads folder
3. Copy/Cut the `.zip` file downloaded previously
4. Open file explorer
5. Navigate to your world
6. Paste the mod in the datapacks folder
7. If you are in your world run /reload
8. Done!

## ⚠️ Requirements
- Minecraft Java version 1.21.8 (mod loaders supported, other versions planned).
- Cheats enabled.
